Privacy policy

Last updated September 30, 2026

Who uses this tool

Claude Gmail is used only by its owner, with the owner’s own Google account. It does not collect data from anyone else.

What data it accesses

With the owner’s permission, the tool reads Gmail messages and labels, applies labels, and creates drafts in the owner’s own mailbox. It does not send email.

Where data goes

Email data is processed by software on the owner’s own computer and by the AI assistant the owner chooses to use. Sign-in credentials are stored only on the owner’s computer. Data is not sold, not shared with third parties for their own purposes, and not used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/connections.
